# Madhinutpam

Modern React + Vite website for Madhinutpam.

## GitHub Pages

Repository name expected by the current Vite config: `Madhinutpam`

After pushing to `main`:
1. Open **Settings → Pages**.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` builds and deploys the site automatically.

The expected URL is:

`https://YOUR-GITHUB-USERNAME.github.io/Madhinutpam/`

If you choose a different repository name, update the `base` value in `vite.config.js` to `/<YOUR-REPOSITORY-NAME>/`.
