# Madhinutpam Modern Website

## Run locally
1. Install Node.js.
2. In this folder run:
   npm install
   npm run dev

## Production build
npm run build

The production site is generated in `dist/`.

## GitHub Pages
For GitHub Pages, deploy the contents of `dist/` using GitHub Actions or a Pages deployment workflow. This React/Vite version is intentionally more modern and interactive than the previous single-file HTML version.
